# Thumb Sight Public 2.9.3-beta — установка

Эта сборка предназначена для Chromium-браузеров. Это **не Firefox-пакет**.
Файл config уже включён в пакет в проверенном публичном виде. Вручную вводить
ключи или менять config не нужно.

Минимальная версия браузера — **Chrome/Chromium 140** (`minimum_chrome_version`
в `manifest.json`). Более старый браузер откажется загрузить расширение;
в этом случае сначала обнови браузер.

## Установка

Распакуй ZIP вида `ThumbSight-Public-Beta-2.9.3-<дата>.zip` в одну постоянную
папку. ZIP напрямую этим способом не устанавливается. После установки папку
нельзя удалять или перемещать: браузер загружает расширение именно из неё.

1. Открой `chrome://extensions` (Chrome), `edge://extensions` (Edge)
   или `opera://extensions` (Opera).
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение» и выбери папку, в которой
   лежит `manifest.json`.
4. Обновление на новую версию: замени файлы в той же папке файлами из нового
   ZIP и нажми «Обновить» / Reload на карточке расширения. Удалять расширение
   и устанавливать заново не нужно: настоящая переустановка может удалить
   сохранённую сессию. Если не уверен, из какой папки загружено расширение,
   сначала посмотри «Путь к папке» в сведениях о расширении.
5. Перезагрузи открытые вкладки YouTube/Pinterest: старые content scripts
   сами не заменяются. В popup расширения должно быть написано `beta 2.9.3`.

## Лицензия

Собственный код расширения распространяется по лицензии MIT — её текст лежит
в файле `LICENSE` внутри ZIP. Уведомления о сторонних иконках интерфейса и их
лицензии — в файле `THIRD_PARTY_NOTICES.md`, он тоже входит в ZIP.

## Проверка после обновления

- Войди в обычный тестовый аккаунт, не в основной аккаунт администратора.
- Выбери язык в popup. Для смены подписей на уже открытых YouTube/Pinterest
  вкладках пока требуется обновить страницу.
- Сохрани обложку через расширение, выбери папку/теги, затем обнови сайт и
  проверь сохранённые связи. Сохранение не должно открывать новую вкладку.
- При ошибке пришли её текст и версию расширения, но не токены, config или HAR.

## Firefox

Совместимая Firefox-сборка пока не выпущена. Этот ZIP и находящийся внутри
`manifest.json` нельзя считать готовым Firefox-расширением. Переименование
ZIP в XPI не добавляет совместимость или подпись Mozilla. Подготовка Firefox —
отдельный этап; отключать защиту браузера ради установки не нужно.
